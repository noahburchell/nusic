*** moving
| up, C-p    | move up                               |
| down, C-n  | move down                             |
| pgup, M-v  | move up a page                        |
| pgdn, C-v  | move down a page                      |
| home, M-<  | move to the first row                 |
| end, M->   | move to the last row                  |
| right, C-f | go to the pane on the right           |
| left, C-b  | go to the pane on the left            |
| tab        | go to the next pane, wraps around     |
| S-tab      | go to the previous pane, wraps around |

*** album artists and albums
| enter on an artist | go to its albums                                               |
| enter on an album  | put the album on top of the queue and play it                  |
| enter on a track   | put the track on top of the queue and play it                  |
| a                  | add the artist, the album or the track to the end of the queue |

*** queue
| enter               | play the queue entry      |
| M-p, M-up, C-up     | move the queue entry up   |
| M-n, M-down, C-down | move the queue entry down |
| del, C-k            | remove the queue entry    |
| M-k                 | clear the queue and stop  |

*** playback
| space | pause or resume, start the queue at its selected entry when nothing plays |
| <     | previous track, restart the track when it is more than 3 s in             |
| >     | next track                                                                |
| ,     | seek back 5 s                                                             |
| .     | seek forward 5 s                                                          |
| r     | repeat the queue, then the track, then nothing                            |
| -     | lower the gain by 1 dB                                                    |
| =, +  | raise the gain by 1 dB, above 0 dB the loudest parts clip                 |
| 0     | set the gain to 0 dB                                                      |
| [     | lower the rate by one step, speed and pitch fall together                 |
| ]     | raise the rate by one step, speed and pitch rise together                 |
| \     | switch the rate between steps of 0.05x and steps of 1 semitone            |
| 1     | set the rate to 1.00x                                                     |

*** other
| C-l    | redraw the screen |
| q, C-c | quit              |

** mouse
| click on a row             | select the row                                                    |
| click on a pane title      | go to the pane                                                    |
| double click               | the same as enter on an album, a track or a queue entry           |
| right click                | the same as a                                                     |
| wheel                      | scroll the list under the pointer                                 |
| click on the play bar      | previous track, pause or resume, next track, repeat               |
| click on the progress bar  | seek to that place                                                |
| click beside a slider knob | move the gain by 1 dB or the rate by one step towards the pointer |
| wheel on a slider          | change the gain by 1 dB or the rate by one step                   |
| right click on a slider    | set the gain to 0 dB or the rate to 1.00x                         |
| click on the rate value    | the same as \                                                     |

** config
=$XDG_CONFIG_HOME/nusic/config=, XDG_CONFIG_HOME defaults to =~/.config=

=KEY=VALUE=, # is a comment

| soft-clip            | false | true or false, above 0 dB bend the loudest parts into full scale, not a hard clip    |
| soft-clip-knee       | 0.8   | 0 to 1, the share of full scale where the soft clip starts to bend, 1 is a hard clip |
| rate-default-unit    | st    | x or st, the steps of the rate at startup, 0.05x or 1 semitone                       |
| always-tabbed        | false | true or false, show the albums and the queue one at a time at every width            |
| sort-ignore-articles | false | true or false, sort the album artists and the albums past a leading a, an or the     |
